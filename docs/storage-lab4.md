# Лабораторная 4: локальное хранение данных

## Где хранятся настройки

| Хранилище | Параметры | Почему |
|---|---|---|
| Shared Preferences (`data/AppPrefs.java`) | логин, пароль, никнейм, офлайн-режим, тема, цветовая схема, размер шрифта | нужны синхронно: при входе и при создании деятельности (`attachBaseContext`, `setTheme`) |
| Preferences DataStore (`data/UserSettingsStore.java`) | ФИО, пол, возраст, название файла | читаются асинхронно на экране настроек |

Проект написан на Java, поэтому DataStore используется через RxJava 3 (`RxDataStore`).
Значения ФИО, пола и возраста, сохранённые раньше в Shared Preferences, переносятся в DataStore
при первом чтении (`SharedPreferencesMigration`).

## Файл с героями

Файл `Documents/heroes_<номер по списку>.txt` записывается после получения каждой порции героев
(`ContentFragment.exportHeroesFile`, `data/HeroesFileStorage.java`). Название можно изменить в настройках,
при этом уже созданный файл переименовывается.

| Действие в настройках | Что происходит |
|---|---|
| Открытие экрана | показываются название, расположение, объём и время создания файла, либо сообщение, что файла нет |
| «Удалить файл» | файл незаметно копируется в `files/heroes_file_backup.txt` внутреннего хранилища и удаляется из Documents |
| «Восстановить файл» (активна, если есть копия и нет файла) | копия перемещается обратно в Documents |

## Разрешения

`READ_EXTERNAL_STORAGE` и `WRITE_EXTERNAL_STORAGE` объявлены с `maxSdkVersion="29"`:
с Android 11 приложение может создавать свои файлы в Documents без разрешений.
На Android 10 и ниже разрешение запрашивается при первой записи файла,
для Android 10 также включён `requestLegacyExternalStorage`.

## Асинхронность

Чтение и запись DataStore идут через `Single` / `Completable`. Операции с файлом выполняются
последовательно в `Schedulers.single()`, результат приходит в главном потоке.
Подписки на чтение отменяются в `onDestroyView`, записи доводятся до конца даже после закрытия экрана.
